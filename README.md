# 🧪 Sistem Booking Ruangan Laboratorium (SiBookLab)

Proyek ini merupakan aplikasi berbasis web yang digunakan untuk melakukan **pemesanan (booking) ruangan laboratorium** secara online. Sistem ini dibuat sebagai bagian dari **Ujian Tengah Praktikum Web Lanjut**.

---

## 📋 Deskripsi Singkat

Sistem Booking Ruangan Lab dirancang untuk mempermudah proses peminjaman laboratorium oleh mahasiswa dan dosen. Dengan sistem ini, pengguna dapat melihat jadwal laboratorium, melakukan pemesanan, serta mengelola data pengguna dan jadwal secara efisien melalui antarmuka berbasis web.
